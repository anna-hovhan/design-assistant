# CodeBlock

A block for commands and file paths: JetBrains Mono on ink, in light text, with rounded corners.

- **Style:** the `code` text style (14px, line height 1.5, weight 500), `code-bg` ground, `code-text`, `radius-code`, 16px by 18px padding, preformatted, scrolling sideways when a line is long.
- **Use it** for what a reader types or reads as a path. A command inside a sentence is a Chip, or inline code in `primary`.
