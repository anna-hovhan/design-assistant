# Chip

A small rounded label for a command, a tool or a tag: JetBrains Mono in a pill with a 1.5px outline.

- **On light:** 14px mono at 500, white fill, a `stroke-outline` border in `periwinkle`, `radius-pill`.
- **On dark (`slide-pill`):** uppercase mono with 0.2em tracking, no fill, a `stroke-outline` border in `outline-on-dark`, white text at 90%.
