# Explainer

One idea taught visually, as a scroll page, a set of slides or a poster, in one self-contained HTML file.

- **Make it** with `/explainer` in the design-assistant repo.
- **Build:** inline CSS and SVG, Google Fonts as the only outside dependency, no JavaScript except slide navigation, responsive down to 375px.
- **Ground:** light for posters, images and scroll pages; slides dark on `bg-midnight` or `bg-indigo`, with a light version available.
- **Parts:** a `tag` eyebrow, a `page-title`, GlassCards with a `card-title` and `body-sm`, step numbers in `label`, commands in CodeBlock and Chip, and arrows in `primary` between steps.
