# GlassCard

The card every light page is built from: white at 70% over the page, a 1px white border, a soft blue shadow and large corners.

- **Style:** `card` fill, a `stroke-card` border in `card-border`, `card-shadow`, `radius-card`, `space-card` padding.
- **Content:** an optional `tag` in `primary` or a step number in `label`, a `card-title`, then `body-sm` text in `text-muted`.
- Light grounds only.
