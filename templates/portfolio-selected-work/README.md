# Portfolio Selected work illustrations

Card images for the portfolio's Selected work section (1200x720 SVG), made in the brand palette from `docs/brand.md`.
Backgrounds use the three deepest gradient pairs, rotated so neighbouring cards differ:
`#0b1560→#2f3dff`, `#2a3cff→#4fd8f0`, `#4d4dff→#ff9ccd`.

- `a/`: the original portfolio illustrations on a new brand gradient, with off-palette colours mapped to the nearest brand colour (for example `#ffb8d9` to blush `#ffb2cf`, `#6d5dfc` to `#4d4dff`). `06-ai-platform.svg` is a redraw, since only a PNG existed.
- `b/`: new white line illustrations (1.5px at card size) with one accent, aqua `#60e7f0` on navy and butter `#ffe7a3` on the others. Not used on the site.
- `final/`: the versions chosen for the site. GTM Engine is `a/` with the grid at opacity .07; AI Strategy is `a/` with its teal elements in indigo `#4d4dff`. The rest match `a/`.

AI workflow automation, AI Application Platform and ML sponsorship recommender kept their existing images on the site, so they appear only in `a/` and `b/`.

These were drawn before `/card-illustration` set its safe area. Some of the `b/` art runs below y=520, where the card's glass panel hides it (the payments wheel, the fourth workflow row), and its strokes are 4 units rather than 4.5. Follow the command, not these files, for placement and stroke width.
