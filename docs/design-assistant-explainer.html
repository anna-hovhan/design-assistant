design-assistant

One line in. One on-brand asset out.

A personal tool that draws tiles and diagrams in the portfolio's look, from the command line or from Claude Code.

The problem

Every visual starts from a blank canvas.

A tile for a case study, a diagram of a system: each one is redrawn by hand and drifts a little from the brand.

The architecture

Five commands, one shared style.

Every command reads the same brand rules. Code generators draw the repeatable shapes; Claude draws the rest.

How it works

Three steps from request to file.

01

Ask

Type a slash command in Claude Code, or run npm run design.

02

Generate

Code generators are pure functions: same input, same output. The rest follows the brand rules.

03

Save

The file lands in out/. Ask for .png or PDF where supported.

Example: /placeholder

A name becomes a tile.

npm run design -- placeholder \ "Sample Text" # -> out/sample-text.svg # label: ST (initials of the two words)

Real generator output. Add --label= to choose different lettering. The same name always gives the same colours.

What to do next

Describe the visual you need.
